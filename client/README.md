# 🛍️ HunarHub

HunarHub is a digital marketplace platform designed to connect local
micro-entrepreneurs with customers and help them showcase their products
and services online.

The project is built with React and focuses on creating a clean,
responsive and user-friendly marketplace experience.

---

## ✨ Features

- Responsive homepage
- Hero section
- Popular categories
- Featured products
- Product listing
- Product details page
- Shopping cart
- Add products to cart
- Remove products from cart
- Cart item count in Navbar
- Total cart price calculation
- Cart state management using React Context API
- Customer dashboard
- Entrepreneur dashboard
- Admin dashboard
- Login and Register pages
- Orders page
- Service Requests page
- Entrepreneurs listing
- 404 Not Found page

---
