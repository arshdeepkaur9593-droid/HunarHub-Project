# 🛍️ HunarHub

> A digital marketplace connecting local artisans, micro-entrepreneurs,
> and home-service professionals with customers.

## 📌 About

HunarHub is a full-stack web development project created to provide a
digital platform for local entrepreneurs to showcase their products and
services.

Customers can explore products and services, view product details, and
manage products through a shopping cart.

The project is currently under development.

---

## 🎯 Main Objectives

- Help local entrepreneurs showcase their work online
- Connect customers with local products and services
- Provide an easy-to-use marketplace interface
- Build a scalable full-stack web application
- Practice real-world React and web development concepts

---

## 🧩 Application Modules

### Customer

- Browse products
- View product details
- Explore categories
- Add products to cart
- Remove products from cart
- View cart total
- View orders

### Entrepreneur

- Entrepreneur dashboard
- Product/service management structure
- Service request management

### Admin

- Admin dashboard
- Application management structure
